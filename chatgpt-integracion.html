ChatGPT en Krueka

OpenCode puede usar la cuota incluida en una suscripción ChatGPT gracias a «Sign in with ChatGPT». Estamos preparando ese mismo tipo de integración para Krueka, pero necesitamos la habilitación correspondiente para una aplicación web alojada.

Solicitar acceso para Krueka

La modalidad para software local de código abierto no puede copiarse sin más a nuestro servidor web. La documentación oficial remite a un formulario para productos alojados.

  1. Abrí el formulario de OpenAI.
  2. Seleccioná «Inicio de sesión y uso del plan de ChatGPT para solicitudes de IA».
  3. Indicá el producto Krueka y la web https://www.krueka.com.
  4. Copiá el texto de descripción incluido debajo. La solicitud no garantiza aprobación.

Los alumnos pueden seguir creando

Krueka Studio conserva el editor visual, los proyectos privados y la Ayuda local sin usar créditos de API. La IA remota existente sigue sujeta al cupo de su proveedor.

La suscripción personal del profesor no se comparte. Cada usuario elegible debe autorizar su propia cuenta. Los niños menores de 13 años necesitan una solución educativa supervisada, no cuentas personales de ChatGPT.

Descripción lista para presentar

Copiá este texto en el campo de productos del formulario oficial.

Krueka es una plataforma educativa web utilizada por docentes y alumnos de primaria y secundaria en Paraguay. Los estudiantes aprenden a crear videojuegos, animaciones y proyectos informáticos desde navegadores, incluso en computadoras de pocos recursos, y sus proyectos permanecen privados. Queremos integrar Sign in with ChatGPT y, si el programa lo permite, la autorización individual del uso incluido en el plan de ChatGPT de cada usuario elegible, mediante un flujo oficial y sin compartir cuentas, suscripciones ni tokens. Nuestra aplicación está alojada remotamente y actualmente usa una API diferente con sus propios límites. Para menores de 13 años necesitamos información sobre las opciones institucionales supervisadas que OpenAI permita sin cuentas ChatGPT individuales. Buscamos controles de edad, consentimiento, seguridad escolar, límites y aislamiento por alumno. Solicitamos evaluar a Krueka como socio educativo para esta integración.

Esta sección no envía solicitudes automáticamente. No se ha creado ninguna conexión OAuth, no se usan credenciales de OpenCode ni se han modificado las cuentas de los alumnos.
