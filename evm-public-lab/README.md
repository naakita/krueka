# Titanteo Security Lab — Public EVM test fixtures

**Only deliberately vulnerable and corrected training contracts.**
This branch belongs to Krueka's repository, but is isolated from `main` and never used by the Krueka website. It exists exclusively to test a real EVM without paid services.

No secret keys, user data, live targets, external RPC, mainnet, or cryptocurrency funds are involved.

Run locally (Foundry): `cd evm-public-lab && forge test -vvv`.
